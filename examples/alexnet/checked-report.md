# AlexNet 复现调查：核对后的课堂示例

本报告对照论文 PDF 和教师 Mac 上的工具输出整理。学生报告中的环境与设备应以各自实测为准。本文件不作为助手输入；原始模型回答仅保存在本地，每次运行会更新 `output/report.md`。

## 论文要求与当前实现

论文使用约 120 万张训练图像（PDF 第 2 页），batch size 为 128（第 6 页），训练约 90 轮（第 7 页）。作者报告在两块 GTX 580 3GB 上训练了 5–6 天。这是原实验的记录，不能直接换算成本机耗时。[原论文](https://papers.nips.cc/paper_files/paper/2012/file/c399862d3b9d6b76c8436e924a68c45b-Paper.pdf)

本机检查的是 torchvision 0.29.0 的模型类：

| 项目 | 论文 | 本机实现 |
| --- | --- | --- |
| 五个卷积层的输出通道 | 96、256、384、384、256 | 64、192、384、256、256 |
| 局部响应归一化 LRN | 使用 | 没有 |
| 第 2、4、5 个卷积层的连接 | 按两块 GPU 分组 | groups=1 |
| 全连接层前的尺寸处理 | 依照论文结构 | AdaptiveAvgPool2d((6,6)) |

前两列依据 PDF 第 3—5 页；本机实现由 inspect_model 读取，另见 [torchvision 源码](https://docs.pytorch.org/vision/stable/_modules/torchvision/models/alexnet.html)。这份模型类不足以证明训练与评估方案已经对齐；本次也没有搜索整台电脑来确认训练脚本是否存在。
